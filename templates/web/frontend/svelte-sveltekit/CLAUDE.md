## Key Commands
- `bun run dev` — development server
- `bun run build` — production build
- `bun run preview` — preview production build
- `bun test` — Vitest unit tests

## Stack Notes
- Svelte 5 runes (`$state`, `$derived`, `$effect`) — no legacy reactive syntax
- SvelteKit file-based routing: `+page.svelte`, `+layout.svelte`, `+server.ts`
- Server-side logic in `+page.server.ts` load functions
- Form actions over API routes for mutations
- Tailwind CSS for styling
